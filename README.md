# 🧠 Memory Game 

SITE: yassezsy.github.io/MemoryGame

A classic memory game with any theme you want, developed entirely in HTML5, CSS, and JavaScript. The game challenges the user to find all the matching pairs of cards.

The project was developed with a **100% Responsive** design, optimized for both desktop PC screens and smartphones.

---

## 🎮 Main Features

- **Customizable Themes:** A dropdown menu to change the visual theme of the cards on the fly.
- **Immersive Soundtrack:** Original Minecraft background music (`minecraft.mp3`) with autoplay and loop enabled.
- **Score System:** Real-time tracking of the score and progress.
- **Restart Button:** Allows you to reset the current game, shuffle the deck, change the theme, and restart instantly.
- **Adaptive Layout:** A fluid interface that resizes to perfectly fit smartphone screens in vertical mode.

---

## 🛠️ Technologies Used

- **HTML5:** Semantic game structure and native audio management.
- **CSS3:** Graphic styling, animations, and Media Queries (`@media`) for mobile adaptation.
- **JavaScript:** Game logic (grid generation, card shuffling, match checking, score management, etc.), handling the entire dynamic part of our game.

---

## 🚀 How to Play

1. Choose your favorite theme from the selection menu at the top.
2. Click on two cards to flip them and reveal their content.
3. If the images match, the cards stay face up and you earn points.
4. If they are different, they will flip back over: memorize their position!
5. Find all the pairs in the fewest moves possible to complete the challenge.
6. Click the **Restart** button to start a new game.
